---
title: Membuka File
description: Empat cara membuka file log di SeeLoggyPlus — File Open, Recent Log Files, drag and drop, serta pencarian dengan Find in Files.
---

Ada empat cara untuk memasukkan log ke viewer:

- **File → Open...** (<kbd>Ctrl+O</kbd>) membuka [File Manager Terpadu](/id/guides/file-manager/) untuk drive lokal dan server remote.
- **Recent Log Files** — klik salah satu entri untuk membukanya kembali dengan mode yang terakhir dipakai (Open atau Tail).
- **Drag & drop** file log ke mana pun di area log.
- **Find in Files** — cari folder remote lalu gunakan **Open & Jump** pada hasil yang cocok.

File besar diindeks di latar belakang. Overlay progres menampilkan fasenya
(indexing, searching, downloading) dengan tombol **Cancel**; file dapat dinavigasi
sepenuhnya begitu pengindeksan selesai.

:::tip
Preferensi **File double-click** menentukan apa yang terjadi saat klik dua kali di File
Manager — **Open/Download** (default) atau **Tail**. Folder selalu terbuka, dan
<kbd>Enter</kbd> mengikuti pengaturan yang sama.
:::
