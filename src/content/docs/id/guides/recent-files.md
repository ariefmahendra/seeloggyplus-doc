---
title: File Log Terbaru
description: Panel Recent Log Files mengingat semua file yang pernah Anda buka, dikelompokkan per server, dan membukanya kembali dalam mode yang sama.
---

Panel kiri mengingat file yang pernah Anda buka, dikelompokkan per sumber (nama server,
atau *Local*).

- Setiap baris menampilkan nama file, path lengkap, dan ukuran file.
- Kotak filter mencocokkan semua kata di seluruh sumber, nama file, dan path.
- Membuka ulang sebuah file memindahkannya kembali ke atas grupnya dan memperbarui waktu
  terakhir dibuka; berpindah tab tidak menulis ulang riwayat.
- Mode terakhir yang digunakan tetap tersimpan: entri dibuka kembali dalam mode **Open**
  atau **Tail** persis seperti saat ditinggalkan.
- **Clear Recent Files** menghapus riwayat; entri yang sedang terbuka juga akan ditutup
  tabnya.
- Panel dapat disematkan atau disembunyikan dengan tombol X atau <kbd>Ctrl+B</kbd>.
