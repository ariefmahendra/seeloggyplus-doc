---
title: Pintasan Keyboard
description: Daftar lengkap pintasan keyboard SeeLoggyPlus untuk file, tab, navigasi pencarian, seleksi, dan log viewer — semuanya dalam satu halaman.
---

| Shortcut | Aksi |
| --- | --- |
| <kbd>F1</kbd> | Buka halaman bantuan |
| <kbd>Ctrl+O</kbd> | Buka Unified File Manager |
| <kbd>Ctrl+W</kbd> | Tutup tab saat ini |
| <kbd>Ctrl+Tab</kbd> / <kbd>Ctrl+Shift+Tab</kbd> | Tab berikutnya / sebelumnya |
| <kbd>Ctrl+F</kbd> | Fokuskan kolom pencarian |
| <kbd>F3</kbd> / <kbd>Shift+F3</kbd> | Kecocokan pencarian berikutnya / sebelumnya |
| <kbd>Escape</kbd> | Hapus pencarian saat ini |
| <kbd>Ctrl+G</kbd> | Lompat ke nomor baris |
| <kbd>Ctrl+R</kbd> / <kbd>F5</kbd> | Muat ulang file saat ini atau sesi tail |
| <kbd>Ctrl+B</kbd> | Tampilkan/sembunyikan panel Recent Log Files |
| <kbd>Ctrl+J</kbd> | Tampilkan/sembunyikan panel Detail |
| <kbd>Ctrl+M</kbd> | Manajemen Server |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Pindahkan seleksi ke atas / ke bawah di log viewer |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Gulir satu halaman ke atas / ke bawah |
| <kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd> | Lompat ke baris pertama / terakhir |
| <kbd>←</kbd> / <kbd>→</kbd> | Gulir horizontal |
| <kbd>Ctrl+C</kbd> | Salin teks yang dipilih (atau seluruh baris saat ini) |
| <kbd>Alt+F4</kbd> | Keluar dari aplikasi |

Tombol navigasi dalam tampilan juga berfungsi saat fokus berada di bagian lain jendela,
tetapi kolom teks, tabel, dan panel Detail mempertahankan perilaku masing-masing.
