SeeLoggyPlus adalah log viewer yang cepat dan ringan untuk developer dan tim operasi.
Aplikasi ini membaca file log lokal dan log remote melalui SSH, memfilter dan mencarinya,
melakukan tailing secara real time, serta memformat payload JSON atau XML yang tertanam.

## Yang dibutuhkan

| Persiapan | Kebutuhan |
| --- | --- |
| Paket portabel dengan JRE | Berjalan langsung di Windows dan Linux; tidak perlu memasang Java. |
| Paket portabel tanpa JRE | Memerlukan Java 21 atau yang lebih baru di komputer. |
| Log remote | Akun SSH di server. Autentikasi kata sandi dan kunci privat didukung. |

## Mulai cepat

<Steps>

1. **Pasang dari Microsoft Store.** Di Windows, pasang [SeeLoggyPlus](https://apps.microsoft.com/detail/9PDJ4N28SNT7) dan jalankan dari Start. Java sudah disertakan.
2. **Memilih portabel?** Unduh paket Windows atau Linux dengan JRE dari [GitHub Releases](https://github.com/ariefmahendra/seeloggyplus/releases/latest), ekstrak seluruh ZIP, lalu jalankan launcher. Lihat [Instalasi](/id/installation/).
3. **Buka log lokal.** Pilih **File → Open...** (<kbd>Ctrl+O</kbd>), lalu pilih file log melalui File Manager Terpadu.
4. **Cari teks.** Ketik `ERROR` di kolom pencarian untuk menyorot dan memfilter baris yang cocok.
5. **Baca detail.** Klik satu baris untuk membacanya utuh di panel **Detail**. Seret untuk memilih teks, lalu tekan <kbd>Ctrl+C</kbd> untuk menyalinnya.
6. **Ikuti baris baru.** Tekan tombol **Tail** di toolbar untuk mengikuti log secara real time.

</Steps>
