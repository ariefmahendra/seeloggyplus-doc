---
title: Opening Files
description: Four ways to open a log in SeeLoggyPlus — File Open, Recent Log Files, drag and drop, and Find in Files.
---

There are four ways to get a log into the viewer:

- **File → Open...** (<kbd>Ctrl+O</kbd>) opens the [Unified File Manager](/guides/file-manager/) for local drives and remote servers.
- **Recent Log Files** — click an entry to reopen it in the mode it was last used (Open or Tail).
- **Drag & drop** a log file anywhere onto the log area.
- **Find in Files** — search a remote folder and use **Open & Jump** on a match.

Large files are indexed in the background. A progress overlay shows the phase
(indexing, searching, downloading) with a **Cancel** button; the file becomes fully
navigable as soon as indexing finishes.

:::tip
The **File double-click** preference decides what a double-click in the File Manager
does — **Open/Download** (default) or **Tail**. Folders always open, and <kbd>Enter</kbd>
follows the same setting.
:::
