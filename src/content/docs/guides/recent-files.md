---
title: Recent Log Files
description: The Recent Log Files panel remembers everything you have opened, grouped per server, and reopens each file in the same mode it was left in.
---

The left panel remembers the files you have opened, grouped per source (a server name,
or *Local*).

- Each row shows the file name, the full path and the file size.
- The filter box matches all words across source, file name and path.
- Reopening a file moves it back to the top of its group and updates its last-opened time; switching tabs does not rewrite history.
- The last used mode is preserved: entries reopen in **Open** or **Tail** exactly as they were left.
- **Clear Recent Files** removes the history; entries that are currently open have their tabs closed as well.
- The panel can be pinned or hidden with the X button or <kbd>Ctrl+B</kbd>.
