---
title: Keyboard Shortcuts
description: Every SeeLoggyPlus keyboard shortcut at a glance — files, tabs, search navigation, selection and the log viewer.
---

| Shortcut | Action |
| --- | --- |
| <kbd>F1</kbd> | Open the help pages |
| <kbd>Ctrl+O</kbd> | Open the Unified File Manager |
| <kbd>Ctrl+W</kbd> | Close the current tab |
| <kbd>Ctrl+Tab</kbd> / <kbd>Ctrl+Shift+Tab</kbd> | Next / previous tab |
| <kbd>Ctrl+F</kbd> | Focus the search field |
| <kbd>F3</kbd> / <kbd>Shift+F3</kbd> | Next / previous search match |
| <kbd>Escape</kbd> | Clear the current search |
| <kbd>Ctrl+G</kbd> | Go to a line number |
| <kbd>Ctrl+R</kbd> / <kbd>F5</kbd> | Reload the current file or tail session |
| <kbd>Ctrl+B</kbd> | Show/hide the Recent Log Files panel |
| <kbd>Ctrl+J</kbd> | Show/hide the Detail panel |
| <kbd>Ctrl+M</kbd> | Server Management |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move the selection up / down in the log viewer |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Scroll one page up / down |
| <kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd> | Jump to the first / last line |
| <kbd>←</kbd> / <kbd>→</kbd> | Scroll horizontally |
| <kbd>Ctrl+C</kbd> | Copy the selected text (or the whole current line) |
| <kbd>Alt+F4</kbd> | Exit the application |

The in-view navigation keys also work while the focus is elsewhere in the window, but text
fields, tables and the detail panel keep their own behaviour.
